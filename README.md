# Guitar Practice Tools

An interactive guitar fretboard to visualize scales and modes in any key and tuning. Click a note to hear it.

**[Live demo](https://dsargento.github.io/guitar-practice-tools.github.io/)**

![Fretboard screenshot](docs/screenshot.png)

Built with Next.js, React, TypeScript, Tailwind CSS and Tone.js.

Mostly built by hand to learn a modern JavaScript stack, with occasional AI use for debugging.

## Run locally

```bash
git clone https://github.com/dsargento/guitar-practice-tools.github.io.git
cd guitar-practice-tools.github.io
npm install
npm run dev
```
